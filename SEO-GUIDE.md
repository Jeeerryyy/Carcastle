## 1. Google Search Console Setup & Indexing

Google Search Console (GSC) is the direct pipeline between your website and Google's indexers.

### Step 1: Verification
1. Navigate to [Google Search Console](https://search.google.com/search-console).
2. Choose **Domain Property** (recommended) and add `carcastlegoa.com`, or choose **URL Prefix** (`https://carcastlegoa.com`).
3. If using URL prefix or HTML Tag verification:
   - Copy the verification code (e.g. `google-site-verification=XYZ123`).
   - Replace the placeholder `[YOUR_GOOGLE_SEARCH_CONSOLE_VERIFICATION_CODE]` in all HTML page `<head>` sections.
   - Alternatively, add the TXT record to your DNS manager (Cloudflare, GoDaddy, Namecheap).

### Step 2: Submit the XML Sitemap
1. In the left navigation menu, click **Sitemaps** under "Indexing".
2. In the "Add a new sitemap" box, type:
   ```text
   sitemap.xml
   ```
3. Click **Submit**. Google will process all 40 URLs across Core, Cars, Services, Locations, and Blog.

### Step 3: Priority Indexing Requests (Day 1)
Use the **URL Inspection** bar at the top to test and click **"Request Indexing"** on your top 5 revenue pages:
1. `https://carcastlegoa.com/` (Home)
2. `https://carcastlegoa.com/pricing.html` (Tariff table)
3. `https://carcastlegoa.com/services/self-drive-car-rental-goa.html`
4. `https://carcastlegoa.com/locations/dabolim-airport-car-rental.html`
5. `https://carcastlegoa.com/locations/mopa-airport-car-rental.html`

### Step 4: Ongoing Monitoring
- **Pages / Coverage Report:** Check weekly for 404s, redirect errors, or unindexed URLs.
- **Performance Report:** Filter by queries containing `"self drive car rental goa"`, `"thar on rent in goa"`, `"car rental mopa airport"`. Target clicks, CTR (aim > 4.5%), and impressions.

## 4. Google Analytics 4 (GA4) & Conversion Tracking

The website already includes `js/analytics.js` which automatically tracks high-value interactions.

### Step 1: Create GA4 Property
1. Go to [analytics.google.com](https://analytics.google.com).
2. Create account: **Car Castle Goa** -> Property: **Car Castle Web**.
3. Create a **Web Data Stream** for `https://carcastlegoa.com`.
4. Copy your **Measurement ID** (`G-XXXXXXXXXX`).

### Step 2: Connect GA4 to the Website
Open `carcastlegoa/js/analytics.js` and paste your ID on Line 6:
```javascript
const GA4_MEASUREMENT_ID = 'G-XXXXXXXXXX'; // Replace with your real ID
```

### Step 3: Built-In Event Tracking
`js/analytics.js` automatically fires and monitors these key custom conversion events:
- `whatsapp_click`: Whenever a visitor taps "Book via WhatsApp", "Chat on WhatsApp", or a car's WhatsApp booking button.
- `phone_call_click`: Whenever a visitor taps `tel:+918767286682`.
- `contact_form_submission`: Whenever a lead submits the enquiry form.
- `car_view`: Whenever a user clicks on an individual vehicle's detail card.

### Step 4: Mark as Key Events (Conversions) in GA4
1. In GA4, go to **Admin > Events**.
2. Toggle on the switch **"Mark as key event"** for `whatsapp_click`, `phone_call_click`, and `contact_form_submission`.
