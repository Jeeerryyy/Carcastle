Supabase & Cloudinary Settings

Car Castle uses Supabase for live PostgreSQL fleet storage and Cloudinary for vehicle photos. If keys are not entered, the admin operates seamlessly in high-speed local mode.

Supabase Dashboard → Project Settings → API → Project URL
Supabase Dashboard → Project Settings → API → `anon` `public` key
Cloudinary Dashboard → Settings → Upload → Upload Presets (Unsigned)
